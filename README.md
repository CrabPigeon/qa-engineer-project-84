- [Первая версия сайта](https://products-store-ru.hexlet.app/)

### Содержание файлов
- **about.yml** — информация о тестировщике
- **requirements.yml** — функциональные, нефункциональные и неявные требования
- **test-cases.yml** — тест-кейсы
- **testing-report.yml** — отчёт о тестировании
- **bugreports.yml** — багрепорты
- **regress-report.yml** — отчёты о регрессионном тестировании
- **screenshots/** — скриншоты багов
